# Валера: Агент RED

2D экшен-комедия в браузере (стиль Contra/Aladdin, вымышленный город Выборгск, страна Лемурия). Vanilla JS + Canvas, без сборки, для GitHub Pages. Git-репозиторий.

## Структура
- `js/engine.js`, `game.js`, `main.js` — движок; `js/levelN.js` — уровни (шаблон — `level1.js`: build → режимы Climb/Arena → генераторы сцен); `cutscene.js` — сюжетные вставки.
- `art_src/` — исходники картинок → `py tools/build_assets.py` собирает атласы в `assets/`.
- Холст 1280x720, логика 640x360. Запуск: превью `valera` (порт 8777). URL-параметры: `?climb`, `?boss`, `?sprites`.
- После смены ассетов повышать `G.VER` и `?v=` в index.html.

## Правила (важно)
- Масштаб всех уровней как в 1–2: камера 1:1, Валера ~84 px из 360, ноги на y=300.
- Графика — только AI-пиксель-арт через Codex (`ask_codex`, ~6–8 картинок за 5 ч), никаких текстур кодом. Фон на весь кадр.
- Лицо Валеры — `assets/valera_head.png`, не менять. Тексты на русском, без символов ← ▼ (нет в шрифте).
- Боссы лёгкие, много анимации. Реальных названий не использовать.
- Подробности (кейинг, тестирование) — в памяти проекта valera-game.
