# Уровень 9 «ПОДЗЕМКА» — концепт (2026-10-15)

ТЗ — L9_TZ.md. Референс Terminator 2D: No Fate: погоня 34–37 мин (вид сбоку, байк уходит по полосам дороги вглубь/к нам, сзади грузовик, спуск в бетонный канал, стрельба на ходу, перевёрнутые машины на пути); платформенные уровни 2–5 мин (ярусы крыш, балконы, лестницы, «прыжок вверх/вниз» сквозь пол, скольжение, враги на разных высотах, фуры-платформы), 19–22 мин (руины и база: ярусы, укрытия «В УКРЫТИЕ», кувырок, бомба, мостки, лазеры, роботы), 45–49 мин (здание: этажи, кабинеты, лифт «на следующий этаж», задания у объектов).
Масштаб — как в ур.1–2 (камера 1:1, Валера ~84 px из 360, ноги на y=300 на нижнем ярусе). Вся графика — Flow (Nano Banana Pro), стиль ур.7–8 (контурный пиксель-арт, крупные головы, как pick_valera.jpg / pick_denis_o.jpg). Без реальных флагов/названий.

## A. Тоннель (капсула)
- Вид сбоку, мир едет вправо. Дорога-маглев из 3 «полос» вглубь (как полосы шоссе у T2D): ↑/↓ — сменить полосу (капсула плавно уходит вглубь/к нам, масштаб 0.92/1.0/1.08, порядок отрисовки по полосе), ←/→ — тормоз/газ (скорость 0.7–1.4), прыжок — магнитный подскок (перепрыгнуть бочку/обломок), огонь — Валера из открытого люка стреляет вперёд/по диагонали (автомат).
- Рельеф: участки с подъёмом «на горку» (камера и полотно поднимаются, задние слои отстают — параллакс по Y), спуски, развилка на верхний/нижний тоннель (выбор полосой), трамплин через разлом.
- Препятствия: капсулы с бомжами/алкашами/гопниками ур.2 (едут медленнее, гопник высовывается и кидает бутылку, бомж машет; таран — урон обоим, капсула врага кувыркается), маглев-поезд из 3 вагонов с ними же (идёт по соседней полосе навстречу или обгоняет — предупреждение красной лампой и гулом за 1.5 с), бочки с бензином (взрыв при касании, выстрел издалека взрывает — огонь на полосе 2 с), упавшие плиты, искрящие кабели, опущенные шлагбаумы, лужи зелёной жижи (занос).
- Сзади — охранная дрезина с киберзаводчанином (как грузовик T2D): стреляет, если отстаёшь; на финише участка её сбивает поезд.
- Зоны фона (переходы «шторкой» внутри кадра, не стыком): служебный бетонный тоннель с лампами → станция-призрак (платформы, на них бомжи у костров) → трубы с зелёной жижей (светится) → огромная пещера под заводом (стройка, краны, на горку) → въезд в шлюз лаборатории.
- HP капсулы = шкала Валеры; смерть — к началу зоны.

## B. Прибытие (катсцена)
Капсула тормозит у перрона лаборатории (искры, пар), колпак откидывается (кадры), Валера вылезает, спрыгивает, оглядывается; ряды капсул уходят вдаль; включается первый телевизор: силуэт Икса в тени — «Что было раньше, яйцо или курица?..».

## C–D. Лаборатория (платформер, как ур.2 по управлению + стрельба в 8 сторон)
Управление: ←/→ бег, ↑/↓ + огонь — прицел вверх/диагональ/вниз (в прыжке), присед, прыжок, ↓+прыжок — спрыгнуть сквозь мостик, ↑ у лестницы — лезть, кувырок/скольжение (как T2D), удар прикладом вблизи, граната.
Мир — набор связанных «комнат-кадров» Flow в разрезе (как заводоуправление ур.7, но с прокруткой и ярусами 2–4 по высоте): склад капсул (стеллажи до потолка, кран-манипулятор едет по рельсу) → конвейерный зал (лента с бомжами/алкашами/гопниками/«ночными бабочками» в одежде — едут к капсулам; лента двигает Валеру) → зал прессов (стеклянные капсулы с людьми, пресс опускается, капсула наполняется зелёной жижей, жижа уходит по трубам — всё анимировано) → вертикальная шахта (вращающиеся колёса-турбины как платформы, подъёмник, падающие капли) → коридор зелёных лазеров (по таймеру, присед/кувырок) → питомник мутантов (клетки ломаются, мутанты вылезают) → зал зелёного дыма (дым ограничивает обзор, вентиляторы сдувают) → двери к Сане.
Элементы ловкости: вращающиеся платформы-колёса, пресс-ловушки по ритму, прыжки по капсулам, едущим на подвесном конвейере, подъёмники, качающиеся крюки (зацепиться и спрыгнуть), обрушивающиеся мостки.
Всё живое: задний план — анимированные ряды капсул, трубы с бегущей жижей, мигающие пульты, пар; передний план — трубы, кабели, стёкла, силуэты поручней (тёмные, проходят быстрее — параллакс 1.3); разрушаемое: стекло капсул, бочки, пульты, трубы (течёт жижа), мониторы.
Персонажи — перед объектами по логике; за решётками/стеклом/колоннами — частично скрыты (полоса переднего плана поверх).
Телевизоры (8 штук) с силуэтом Икса — по фразе из ТЗ, срабатывают при подходе; их можно разбить, Икс обижается («Я устал прощать»).

### Враги
Киберзаводчане (лица по фото владельца, комбинезоны, кибер-части, ноги шагают):
1. «Шляпа» (лицо worker_hat): кибер-нога-пружина, прыгает между ярусами, кидает горящие бутылки дугой.
2. «Очкарик» (лицо worker_glasses): рука-сварка — короткий луч-резак в упор, щит-маска сварщика блокирует выстрелы спереди (бить сзади/сверху/гранатой).
3. «Обрубок»: торс на гусеничке, ползёт по полу и стенам, взрывается спиртом рядом.
4. «Летун»: реактивный ранец из огнетушителей, пикирует с дрелью.
Мутанты-спецназовцы (уродливые, одна огромная рука и т.п.):
5. «Клешня»: огромная рука, удар по полу — волна; держит выстрелы рукой как щитом.
6. «Плевун»: плюёт зелёной кислотой навесом, лужа жжёт 2 с.
7. «Потолочник»: ползает по потолку, падает сверху.
8. «Суперсолдат»: миниган, длинная очередь с раскруткой (телеграф), много HP; с него падает миниган.
Каждый — своя смерть (искры/спирт/жижа), свой звук.

### Оружие (только ур.9)
Автомат (бесконечный), миниган (очередь, разброс), плазмоган (зелёный шар, пробивает насквозь), ракетница (взрыв, сносит предметы), гранаты (дугой, 5 шт.), секрет — «Осеменитель 6000»: стреляет семечками, которые прорастают на враге/полу в подсолнух-мину и взрываются через 1 с (цепная реакция), спрятан в тайной комнате за разрушаемой стеной в шахте. Подбор — ящики/с врагов; патроны спецоружия конечны, при пустом — автомат.

## E. Саня
Катсцена: лаборатория Сани (хирургический стол, робот-паук и робот-собака на столах, огромные 3D-принтеры вдоль стен), диалог из ТЗ дословно. Саня садится в капсулу-сканер под бронестекло, жмёт кнопку, смеётся; принтеры печатают Саньков.
Бой: длинный зал вправо (прокрутка вперёд), 6 принтеров (по 2 на ярусах), у каждого аккумулятор на стене — стрелять (вверх/диагональ), принтер взрывается и перестаёт печатать. Саньки: бегут с гаечным ключом, прыгают, некоторые недопечатанные (ползут половинкой). Сканер едет по потолочному рельсу за Валерой: сбрасывает лучом-сканером «печать» на пол (зона, где сразу появляется Санёк), стреляет скобами. После последнего аккумулятора вагонетка искрит, Саня в панике колотит стекло, взрыв. Дверь открывается.

## F. Зал славы
Коридор: телевизоры с боссами игры (Наташа, Кеша, таракан, Ванделорд, Граблионок, главарь спецназа, петух/паук/мегаробот — кадры из прошлых уровней внутри рамок ТВ), постамент с рулонами туалетной бумаги с лицом Валеры. Икс с ТВ — реплика из ТЗ. Валера комментирует.

## G. Закрытый цех
Без врагов, но не пусто: ковши разливают жижу, зелёные огненные факелы по таймеру, качающиеся цепи с ковшами (проход по ритму), конвейер, дым, искры, вспышки. 3 яруса. Выход на мостик над чаном.

## H. Разоблачение
Мостик, в чан льётся струя. Икс в тени на середине → выходит: Кеша (спрайты ур.2). «Кеша, не может быть!» Срывает маску — Граблионок. «Это всё был ты?» Срывает маску — Семён (фото владельца). Диалог из ТЗ. Флешбеки (сепия, кадры на движке из сцен прошлых уровней): Кеша и Граблионок рядом с Валерой. Флешбеки устранения — мультяшно, без крови: Кешу Семён сталкивает в чан (пузыри и шляпа), Матиз Граблионка с ним внутри уезжает под пресс («хрусть» за кадром, вылетает колпак колеса).

## I. Босс Семён (5 фаз по 20 %)
Арена — мостик над чаном + боковые площадки и укрытия (ящики, щиты, трубы) + верхние балки. По краям висят 2 стропы от ковшей с жижей над ареной. Валера дёргает стропу (↑ рядом) — ковш опрокидывается туда, где сейчас Семён (с задержкой 0.6 с, телеграф тенью). Попал — Семён облит, искрит, 6 с уязвим: Валера «звереет» (красная аура, серия ударов кулаками и прикладом, каждый удар 1–1.5 %, максимум 20 % за серию). Стропа восстанавливается 10 с (ковш поднимается, видно). Пули по Семёну не наносят урона (рикошет/блок рукой), но сбивают атаку.
Фазы: 1) рука-кнут, цепляется за балки и перелетает, ракеты из руки; 2) лазер из руки, удар рукой издалека (рука вытягивается через пол-экрана); 3) реактивные ботинки — летает, призывает киберзаводчан и мутантов; 4) невидимость (виден только по искажению), зелёные молнии в пол; 5) всё сразу + дождь из зелёной жижи (укрытия спасают), рука хватает Валеру и бросает.
Победа: Семён шатается, падает с мостика в чан.

## J. Финал
Валера садится на пол: «Что-то я проголодался.» Чан бурлит, экран трясётся, голос Семёна: «Валера, я тебе не какой-то там проходнячок.» Конец уровня, итоги.

## Бесшовность фонов (как ур.8)
Длинные зоны: кадр Flow [левый край | повторяемая середина | правый край] + зеркальные/сдвинутые повторы с маской-переходом в сборщике; переходы между зонами — нарисованные перегородки/шлюзы/колонны спереди. Параллакс 4 слоя: дальний (0.2), средний (0.5), игровой (1.0), передний (1.3, тёмные силуэты). Анимации фона — отдельные спрайты (капсулы с жижей, прессы, трубы, лампы), не код.

## Баланс
Чекпоинты каждые ~40 с; 3 жизни на часть; аптечки (кефир/пирожки как раньше). Боссы: Саня — 6 аккумуляторов по 8 попаданий; Семён — 5 серий, промахнуться ковшом можно (он уворачивается в фазах 3–5 с шансом 30–50 %).

## Арт для Flow (порядок)
1. Капсула Валеры сбоку (лист), капсулы бомжей/гопников, поезд, дрезина, бочки/взрывы; фоны тоннеля 5 зон × (дальний+средний), полотно с рельефом, передний план.
2. Валера сбоку с автоматом: бег, стоя, прицел 5 направлений, прыжок-сальто, присед, лестница, кувырок, удар, ранение/смерть, «звериный» удар; оружие — отдельные листы позы с миниганом/плазмой/ракетницей/О-6000.
3. Лаборатория: 7 зон-фонов, анимации (капсулы-прессы, конвейер с людьми, трубы с жижей, лазеры, дым, колёса, ТВ с Иксом), предметы и передний план.
4. Враги 1–8 (по листу на тип, фото-референсы лиц).
5. Саня (портрет, листы), принтеры, аккумуляторы, сканер на рельсе, Саньки, роботы на столах, фон.
6. Зал славы, цех, мостик/чан, Семён (портрет, листы, рука, ракеты, молнии, полёт), маски Кеши/Граблионка, флешбеки, финал.

## 10. Правки по критику (2026-10-15) — важнее текста выше
- Оружие: + пистолеты (стартовое спецоружие: быстрые одиночные, дальность больше). Кувырок с неуязвимостью 0.3 с; скольжения нет.
- Части: зал славы — начало цеха; цех растянут до 2:30 (3 яруса, ковши, факелы, цепи, задание у объекта). Лаборатория: по 3 зоны на часть (~50 с каждая) с аттракционом: C — склад капсул / конвейер / подъёмник с запрыгивающими врагами; D — зал прессов (перекрыть 3 вентиля, чтобы остановить пресс и открыть проход) / шахта с колёсами / лазеры+дым. Укрытия «В УКРЫТИЕ» у ящиков, турели на стенах.
- Фразы Икса: яйцо/курица — прибытие; Выборгск прогнил — конвейер; лучший финал — прессы; жалкие попытки — шахта; чёрная комната — зал дыма; устал прощать — первый разбитый ТВ; + 2 ТВ на станции-призраке в тоннеле (повтор «Тебе не накопить на квартиру» / «Выжму все соки»); «присоединяйся» и «квартира в столице» — Семён между фазами. Во время игры — плашка без паузы; длинные диалоги — пропуск по фразам.
- Враги «Обрубок» и «Летун» — тоже по двум фото (другая кибер-часть). Минимум на врага: ходьба 6–8 кадров со сменой ног, атака 4, удар 1, смерть 4.
- Тоннель: полосы различаются смещением по Y ±28 px + тень + порядок отрисовки, смена 0.25 с; горка — на всё полотно сразу; развилки нет. Бочка/плита — маркер-тень за 1 с. Не больше 3 видов угроз сразу. Дрезина стреляет, если скорость < 0.9 дольше 2 с. 2 ТВ на станции. Капсула ~150x70, голова Валеры ~24 px.
- Саня: батареи выше уровня Валеры (стрелять вверх/45°), прочность 20, щиток открывается каждые 4 с; живых Саньков ≤ 6, точка печати сканера ≤ 1 за 3 с; фоновые принтеры (без логики) взрываются цепочкой. Саня в катсцене сваривает робота-собаку (искры, дёргается лапа).
- Семён: 3 ковша над фиксированными зонами (левая, центр, правая) на стропах у краёв; заманить в зону и дёрнуть, тень 0.6 с; пули сбивают его в стан на 1.5 с (окно для ковша); уклоняется только если не оглушён. Серия: 4 % за удар, до 5 ударов за 5 с → ровно 5 обливаний = 5 фаз. Подкрепления с фазы 2: раз в 25–30 с по 2, не больше 3 одновременно, не во время окна. Перила; падение только от броска рукой в фазе 5 — урон и возврат на мостик. Невидимость — лист «мерцания» из Flow.
- Цветовой код: опасное — лаймовое с белым ядром + красное предупреждение; снаряды врагов — оранжевые/красные; пули Валеры — жёлтые, плазма — голубая; фоновая жижа — тёмная, приглушённая.
- Арт: платформы/мостки/лестницы/перила — отдельные спрайты, фоны без игрового пола; 2–3 разных кадра на зону, стыки за колоннами переднего плана; дальние слои с запасом по высоте; кей только на пурпурном; эффекты на чёрном (lighter). Передний план ≤ 15 % кадра. Сепия флешбеков — при сборке. Маски Кеши/Граблионка — реквизит + облако пыли при смене.
- Флешбеки и зал славы — только из существующих сцен/спрайтов: проверить по уровням 1–8, где были Кеша и Граблионок и кто боссы.
- Порядок: пробный кусок тоннеля (30 с) и склада капсул (40 с) → критик → дальше по частям; после каждой — бот, коммит, push, G.VER.
