# Пейджер — все сообщения и когда они приходят

Код: `js/hud.js` (объект `Pager`, ~строка 232). Подсказки уровней идут через `Game.drawHint` (`js/game.js:715`) → `Pager.tip(...)`.
`{punch}`, `{jump}` и т.п. заменяются на клавиши текущего устройства.

## 1. Общие правила (что регулирует частоту)

| Правило | Значение сейчас | Где менять |
|---|---|---|
| Игра на паузе, пока сообщение на экране | да; закрыть можно через 0.7 с (прыжок/старт/удар/бросок) | hud.js, Pager |
| Не показывать во время катсцены, затемнения, перехода, респауна, смерти | да | `live(lv)` |
| Пауза после любого затемнения | 2.5 с (`calmT`) | hud.js |
| Минимум между подсказками | **12 с игрового времени** (`gap >= 12`); подсказка босса — без ожидания | hud.js |
| Каждая подсказка — один раз за уровень | да (`tips[text]`) | hud.js |
| Подсказка босса — один раз | да (`seen[id]`) | hud.js |
| Банк: не во время боя с боссом, не при очереди, минимум **50 с** после прошлого сообщения | да | hud.js |

## 2. Банк ЛЕМУРБАНК (случайные события, каждый уровень)

Время — только игровое (паузы и катсцены не считаются).

| Событие | Когда | Шанс |
|---|---|---|
| Списание №1 | 40–100 с | всегда |
| Код «никому не говорите» | 110–230 с | 30% |
| Списание №2 | 170–260 с | всегда |
| Списание №3 | 320–400 с | ур.6 — всегда, остальные — 25% |
| Магазин «Под горлышко» (ур.2, при входе в магазин) | сразу | всегда, 1800–3400 Р |

Итого обычно **2–3 банковских сообщения на уровень + реакция Валеры** (реплика, 3 топота, тряска экрана после каждого).

Формат: `СПИСАНИЕ X Р / <причина> / ОСТАТОК: Y Р`. Сумма подбирается так, чтобы к концу уровня остаток стал стартовым следующего:
ур.1 37 420 → 2: 31 600 → 3: 25 200 → 4: 18 900 → 5: 12 700 → 6: 6 400 → 7: 0 → 8: −2 100 → 9: −4 500 → 10: −6 900 → 11: −9 400.

**Причины списания (случайно):** Налог на плитку для столицы · Сбор на подогрев столичных тротуаров · Налог на воздух (не столичный) · Взнос на фонтан для мажоров · Сбор за проживание вне столицы · Налог на дождь · Взнос на ёлку главной площади · Налог на пельмени · Сбор на парковку столичных мажоров · Налог на усталость · Взнос на столичный салют · Сбор за тишину · Налог на гордость за столицу · Взнос на яхту для столичного фонда · Сбор за пользование солнцем · Налог на отсутствие налогов · Взнос на новый газон столицы · Сбор за дыхание

**Реакция Валеры (случайно):**
- Гребаные мажоры из столицы! Все деньги у меня выкачали!
- Опять?! Да чтоб вас, мажоры столичные!
- Это ж полсмены! Ворюги столичные!
- Я на пельмени копил! Гребаные мажоры!
- Кто им разрешил?! Все деньги выкачали!
- Остаток ровно 0: «НОЛЬ?! Гребаные мажоры из столицы, всё до копейки выкачали!»
- Ушёл в минус (+ строка «СЧЁТ УШЁЛ В МИНУС»): «В минус?! Я теперь ещё и должен этим мажорам?!»

**Код:** «Никому не говорите код: 3671. Даже сотруднику банка.» → Валера: «Три... шесть... семь... один. Ага, никому не скажу!»

## 5. Почему кажется «слишком часто»

- Подсказки на ур.1, 4 и 7 идут почти каждой зоной — разрыв всего 12 с, и каждая ставит игру на паузу.
- Банк + реакция Валеры — 2–3 раза на уровень, каждое со стопом игры и тряской.
- На ур.4 «Тут не пройти — пригнись» может повторяться каждые 4 с (единственная повторяемая подсказка).
- В бою с боссом может прийти две подряд: подсказка уровня + ДОБРОЖЕЛАТЕЛЬ (ур.4, ур.7).
