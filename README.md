# Валера: Агент RED

2D-боевик с юмором в духе Contra / Aladdin (90-е). Северодвинск, 2000-е.
Чистый HTML5 Canvas + JavaScript — без сборки и без зависимостей, вся музыка и звуки синтезируются в браузере.

## Уровень 1 — «Севмаш. День первый»
- Катсцена: вид на Севмаш (эллинг цеха 55, портальные краны, трубы ТЭЦ, Никольская церковь, пятиэтажки) → «ДЕНЬ ПЕРВЫЙ».
- Катсцена в цеху: стропы, «Вира!», каска об пол, кирпич с неба.
- Вертикальный подъём на кран (~5 минут): падающие кирпичи/болты/ключи/бутылки, крысы, чайки, пьяные слесари, пар, искрящие провода, гнилые поддоны, грузы на крюке, лифт, лестницы, контрольные точки, секретные значки «Ударник».
- Босс: Наташка-крановщица (бутылки, пощёчины, таран; слабые места — когда пьёт и когда оглушена; бутылку можно отбить ударом обратно).
- Финал: служебная записка, «смена кончилась», спецназ из Индии: «Это агент RED!».

## Управление
| Действие | Клавиатура | Геймпад |
|---|---|---|
| Бег | ← → / A D | крестовина / стик |
| Лестница | ↑ ↓ / W S | крестовина |
| Прыжок | Z / Пробел / K | A |
| Спрыгнуть с балки | ↓ + прыжок | |
| Удар (серия из 3 — апперкот) | X / J | X |
| Бросок | C / L | B |
| Сменить снаряд | Q / V | Y |
| Пауза / пропуск сценки | Esc / P | Start/Select |
| Звук | M | |

На телефоне появляются экранные кнопки (лучше держать горизонтально).

## Запуск локально
```
py -m http.server 8777
```
и открыть http://localhost:8777

## Публикация на GitHub Pages
1. Создать репозиторий и запушить папку.
2. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Игра будет доступна по адресу `https://<логин>.github.io/<репозиторий>/`.

## Параметры для разработки
- `?climb` — сразу подъём, без катсцен
- `?boss` — сразу бой с Наташкой
- `?sprites&scale=3&style=valera` — все позы персонажа крупно

## Структура
- `js/engine.js` — экран, ввод (клавиатура/геймпад/тач), звук и музыка (WebAudio), частицы, текст
- `js/humanoid.js` — скелетная анимация персонажей, позы, лица
- `js/art.js` — фоны и пропсы (Севмаш, цех, подлодка, краны, предметы)
- `js/game.js` — физика, Валера, враги, снаряды, подбор, HUD
- `js/cutscene.js` — движок катсцен и диалогов
- `js/level1.js` — уровень 1: генерация, фоновые рабочие, босс, сцены
- `js/main.js` — меню, пауза, итоги, музыка, главный цикл
- `js/sprites.js`, `js/sprites_data.js` — атласы спрайтов и анимации
- `assets/` — готовые фоны и атласы спрайтов

## Графика
Исходники сгенерированы нейросетью (image_gen) по референсам в едином стиле и лежат в `art_src/` (в git не попадают — тяжёлые).
`py tools/build_assets.py` — вырезает зелёный/чёрный фон, нарезает кадры, выравнивает по ногам и собирает атласы в `assets/`.
