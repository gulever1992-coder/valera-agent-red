# Валера: Агент RED

2D-боевик с юмором в духе Contra / Aladdin / Cuphead. Вымышленный город Выборгск (страна Лемурия), 2000-е.
Чистый HTML5 Canvas + JavaScript — без сборки и зависимостей; музыка и звуки синтезируются в браузере.

**Играть:** https://gulever1992-coder.github.io/valera-agent-red/

## Уровни
| № | Название | Что внутри | Босс |
|---|---|---|---|
| 1 | Севмолот | подъём на кран, крысы, чайки, пьяные докеры | Наташка-крановщица |
| 2 | Дорога домой | вечерний Выборгск, гопники, панки, собаки | Кеша |
| 3 | Глюки | квартира Валеры, насекомые-глюки | Царь-таракан |
| 4 | Дикие кошки | клуб, зомби-гости, спасение Вовы | Байкер |
| 5 | Погоня | вид сверху, милиция, гонка | Граблионок на «Матизе» |
| 6 | Грибной дождь | лес, болото, дюны, волшебная палочка | Ванделорд |
| 7 | Заводоуправление | стелс под дождём, здание в разрезе, главный зал | Главарь спецназа |
| 8 | Закулисье | тир со спины, зомби, роботы | Петух, Паук, Мегаробот |
| 9 | Подземка | капсула, лаборатория, профессор Саня | Семён |
| 10 | Финал | крыши, небо, море | Гигант-Семён |

В главном меню — **Энциклопедия злодеев**: все враги игры с анимациями атак и биографиями.
После 10 уровня — **финальные титры**.

## Управление
| Действие | Клавиатура | Геймпад |
|---|---|---|
| Бег | стрелки / A D | крестовина / стик |
| Лестница | вверх / вниз, W S | крестовина |
| Прыжок | Z / Пробел / K | A |
| Удар (серия из 3 — апперкот) | X / J | X |
| Бросок | C / L | B |
| Сменить снаряд | Q / V | Y |
| Пауза / пропуск сценки | Esc / P | Start / Select |
| Звук | M | |

На телефоне появляются экранные кнопки (держать горизонтально). В уровне 8 прицел — мышью.

## Запуск локально
```
py -m http.server 8777
```
и открыть http://localhost:8777

## Структура
```
index.html          страница игры (холст 1280x720, логика 640x360)
js/engine.js        экран, ввод, звук, частицы, текст
js/music.js         музыка: свой трек на уровень, металл на боссах (?jukebox — плеер)
js/game.js          физика, Валера, общие враги, снаряды, HUD
js/cutscene.js      катсцены и диалоги
js/sprites*.js      атласы спрайтов и анимации
js/levelN*.js       уровни 1–10 (у больших уровней несколько файлов)
js/*_data.js        разметка листов и карт (собирается скриптами из tools/)
js/extras.js        энциклопедия злодеев и финальные титры
js/main.js          меню, выбор уровня и сложности, итоги, главный цикл
assets/             фоны, атласы, портреты, обложки, шрифт (.webp — сжатые копии)
tools/              сборщики ассетов (Python) и вспомогательные скрипты
docs/               ТЗ и концепты уровней 7–10
```

## Параметры для разработки
- `?l2` … `?l10` — сразу нужный уровень (`?l2boss`, `?l6boss`, `?l9=lab`, `?l10=intro` и др.)
- `?best` — энциклопедия злодеев, `?credits` — финальные титры
- `?sprites&scale=0.5` — все атласы на одном экране

## Графика
Пиксель-арт сгенерирован нейросетями по наброскам автора. Исходники лежат в `art_src/` и в репозиторий не попадают (тяжёлые).
После смены картинок: `py tools/build_*.py` → `py tools/optimize_assets.py` (делает .webp-копии), затем поднять `?v=` в `index.html`.

Все персонажи, города и страны вымышлены.
